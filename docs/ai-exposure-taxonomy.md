# AI exposure taxonomy

Version `2026-07-28` reserves direct classifications for: AI infrastructure, semiconductors, cloud/platforms, model/software providers, data/automation, and AI-enabled applications. A security is classified only when a maintained first-party or licensed metadata source explicitly maps it to one of these categories. Without that data AlphaPilot returns `NOT_AVAILABLE`; it does not infer AI exposure from a ticker, name, or sector. ETF and mutual-fund look-through is not reported unless constituent data is present.
